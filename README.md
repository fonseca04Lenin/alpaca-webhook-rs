This project will hopefully be a lightweight, high performance webhook receiver built in Rust that bridges TradingView strategy alerts (or similar signal providers) to the Alpaca Markets trading API. It runs as a local or VPS hosted server using Axum for the async HTTP endpoint, securely listens for incoming POST requests containing trade signals (Ex: buy/sell actions, symbols, quantities), validates them with optional secret key checks, and automatically submits market or limit orders to your Alpaca account via the official REST API (supporting paper trading for safe testing). Designed for reliability in automated trading setups, it emphasizes low resource usage, strong error handling, logging with tracing, environment based configuration for API keys, and easy deployment as a single compiled binary ideal for DIY traders who want a fast, crash resistant alternative to Python based bridges without sacrificing control or security.
